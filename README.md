# （DASFAA2025) UniMixer: Unified Patch-Wise and Global Inter-Series Dependency Modeling for Multivariate Time Series Forecasting

This official repository contains PyTorch codes for UniMixer: Unified Patch-Wise and Global Inter-Series Dependency Modeling for Multivariate Time Series Forecasting paper.

# Get Started

1. Dataset can be obtained from Time Series Library at [GitHub - thuml/Time-Series-Library: A Library for Advanced Deep Time Series Models.](https://github.com/thuml/Time-Series-Library) and codes of iTransformer at [GitHub - thuml/iTransformer: Official implementation for &quot;iTransformer: Inverted Transformers Are Effective for Time Series Forecasting&quot; (ICLR 2024 Spotlight), https://openreview.net/forum?id=JePfAI8fah](https://github.com/thuml/iTransformer) .

2. The required runtime environment is the same as the standard environment required by Time Series Library.

3. All optimal parameters are placed in the **unimixer_scirpts** directory according to the dataset. However, we note that this model is strongly influenced by the parameters in some of the datasets, and the parameters may be slightly different in different runtime environments.
